# Atlas research

Research artifacts use a dated snapshot where possible. Each project should identify one canonical structured source, a human-readable summary, derived exports, and a clearly named review queue. Raw source captures and downloaded evidence belong in `raw/` or the project’s asset folder.

Use [`PROJECT-TEMPLATE.md`](PROJECT-TEMPLATE.md) when starting a new research project.

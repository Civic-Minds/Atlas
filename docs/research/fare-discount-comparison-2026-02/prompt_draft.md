# Transit Discount Program Comparison Prompt

Please conduct a comprehensive comparison of transit fare discount programs for low-income riders across the following regions:
1. **San Francisco Bay Area** (Specifically "Clipper Start" for BART and other agencies)
2. **Los Angeles** (LIFE Program / Metro)
3. **San Diego** (PRONTO / MTS / NCTD)
4. **two other major California cities** (e.g., Sacramento, San Jose/VTA)

For each region/program, please provide the following specific data points in a structured format (preferably a table):

*   **Program Name**: What is the specific name of the low-income discount program?
*   **Qualifying Income Level**: What is the exact income cutoff for a single-person household? (Please specify if it's based on Federal Poverty Level percentages, e.g., 200% FPL).
*   **Discount Amount**: What is the specific discount offered? (e.g., "50% off single rides", "20% off monthly passes").
*   **applicability**: Does this apply to all transit modes in the region or only specific agencies (e.g., bus vs. rail)?
*   **Verification Method**: How do riders prove eligibility?

Finally, please analyze the data to answer:
*   Which city offers the most generous discount percentage?
*   Which city has the most accessible income threshold (i.e., easiest to qualify for)?

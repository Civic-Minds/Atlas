# Transfer-policy inventory

Snapshot date: 2026-10-01. Scope: all 693 agencies in the Atlas registry.

Canonical files:

- `transfer-inventory.json` — complete structured ledger.
- `transfer-inventory.csv` — flat export.
- `transfer-inventory.md` — human-readable summary.
- `transfer-research-queue.csv` — agencies needing additional research.
- `manual-verified-transfers.json` — source-backed policy records used to build the ledger.
- `official-site-review.json` — official-site discovery evidence for all 693 agencies.
- `transfer-base.json` — registry input used for the snapshot.

The JSON ledger is authoritative. CSV and Markdown are derived views and should be regenerated after ledger changes.
